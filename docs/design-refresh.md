# Site design refresh — October 10, 2026

The shared header, service image dropdown, footer, blue/white palette and local Oswald font now apply to all page types. Existing URLs and metadata are retained. The homepage keeps its established layout. Service pages, four local pages, About, Contact, Finishes, Learning Center hub/categories/articles, privacy and not-found views use the same visual system.

## Content basis

Original copy draws on the existing Learning Center (30 articles), existing service specifications and these publicly reviewed Jacksonville competitors:

- https://sharkfloorcoatings.com/why-us/ — installation sequence, preparation, repairs, decorative broadcast, finish and customer questions.
- https://polyshieldcoatings.com/ — consultation, concrete evaluation, installation planning and aftercare presentation.
- https://epoxyflooringjax.com/ — price/scope visibility and organization of coating options.

Competitor warranties, certifications, reviews, one-day guarantees, antibacterial assertions, strength multipliers and chemical-resistance absolutes are not adopted. There is no invented project portfolio. Added service copy explains complete coating builds, cure versus installation time, quote scope, sample selection, existing flooring and local use conditions. Learning Center article text, source references and schema are retained, with cover imagery and a linked contents list added.

## New image assets

Built-in image generation created six individual landscape architectural photograph-style concept scenes. Optimized WEBP assets are in `public/images/finishes/`. All page displays identify them as design visualizations. These are neither completed projects nor exact product samples.

Shared prompt: natural daylight, plausible resin finish with fine variation and soft reflections, floor occupying the lower 55% of the frame, uncluttered upscale Florida architecture, no people, logos, text, watermarks, borders or collage.
